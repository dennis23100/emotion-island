# 情緒不孤島 v2.0 — Visual Production Pass I

這一版的原則：**凍結核心功能，升級視覺／動畫／鏡頭／聲音。**

## Core Freeze（刻意不重寫）
- Firebase / local demo 資料結構
- `0905` 主活動房 + `090501~090508` 組別房代碼
- 累積加分
- 商店 / 可用分數
- 家具佈置 / 碰撞 / 儲存
- 小精靈資料
- 主辦方 viewer mode

## 1～8 Production Priorities

### 1. 地形美術
八組新增 Production Terrain Layer，不只靠換色：不同草地區、觀景區、森林群、月汐潟湖、花野、水晶帶、極光祭壇區。

### 2. 資產品質
保留既有 GLB Asset Bank，並新增 Material Polish：降低過度金屬感、統一 roughness，讓程序物件和 GLB 不那麼像兩套素材。

### 3. NPC 使用設施
小精靈不只走到遊樂設施旁：旋轉木馬／咖啡杯／飛椅／軌道會繞著設施運動，摩天輪會有上下乘坐感，彈跳床會跳，小火車會繞行。

### 4. 大／中／小尺度
新增較大的主題地形塊、既有中型建築與小型 clutter，避免所有東西尺寸都差不多。

### 5. 材質層次
新增 MeshStandard production layer，保留原本 toon 美術，但在地形分區和大型物件上增加 roughness / material hierarchy；不是靠開大 Bloom 變漂亮。

### 6. 鏡頭
新增：
- `◉ 最佳視角`：八組各自有構圖預設
- `◌ 巡航`：慢速 cinematic orbit
- 玩家一手動拖曳／縮放，巡航立即停止

### 7. 環境音
新增 `♪ 環境音`。使用瀏覽器 WebAudio 即時生成低音環境層與柔和風聲，不需要額外 mp3，也不會增加部署檔案。各組基礎音高略有不同。

### 8. 里程碑演出
400 / 800 / 1200 / 1600 四個 milestone 新增場景光環層，並隨進度逐步提升氣氛亮度；不是到 1600 才突然完成。

## 建議測試順序
1. 不帶 `?room=` 開 `emotion_my_world.html`
2. 切換 1～8 組，看最佳視角差異
3. 開啟巡航
4. 第一次點環境音（瀏覽器要求使用者手勢後才允許播放）
5. 加分測 400 / 800 / 1200 / 1600 門檻
6. 商店購買、佈置、移動、儲存
7. 再測 `?room=090501` 與 `?room=090508`

## 注意
WebAudio 必須由使用者點擊按鈕後啟動，這是瀏覽器的 autoplay 安全規則，不是 bug。
