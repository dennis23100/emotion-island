# 情緒不孤島 v1.6 — Solid Island / Color Fidelity / Shop Expansion

這一版專門處理 v1.5 實測時最明顯的四個問題：浮島底部像被光線穿透、切換組別失效、商店太雜且物件太少、整體曝光過高與白色光暈過強。

## 1. 浮島底部不再像透明

v1.5 的「穿透感」不只來自地形本身，也來自 selective bloom 的作法：只有發光物件被送進 Bloom pass 時，沒有發光的島體沒有在 Bloom pass 裡當遮擋物，因此島後面的光線有機會看起來穿過岩層。

v1.6 改成：
- Bloom pass 仍然保留完整場景深度遮擋。
- 非發光物件在 Bloom pass 暫時改成黑色遮擋材質，再恢復原材質。
- 小世界主島額外加入一層實心內核與底部封蓋。
- 瀑布與環形光帶降低透明發光強度。

結果：岩壁應該要呈現實心遮擋，後方光效不應再直接「透過」島體。

## 2. 切換組別重寫

- 切換前先停止舊組 listener。
- 清除舊 group / layout draft。
- 重建新的組別世界後，再監聽新組資料。
- URL 仍會同步更新 group / 090501～090508 room code。
- 開發版 localStorage lock key 升為 V16，避免舊版第一組鎖定殘留。

目前仍開放右上角「切換組別」，方便檢查八組主題。

## 3. 商店重新分類，全部固定 100 pt

分類：
- 自然
- 建築
- 休憩
- 燈飾
- 水景
- 活動

共 31 種可購買物件，所有物件固定 100 pt。

新增例子：
- 森林灌木、蘑菇叢、山林松樹、景觀岩石
- 彩色小木屋、森之鳥居、星空帳篷、小風車
- 茶會桌椅、樹間吊床、小世界路牌
- 星星路燈、月牙燈、螢光精靈燈
- 山水小池、睡蓮池
- 小小音樂台、風景畫架

商店上方可直接切分類，不需要一次捲完全部物品。

## 4. 不再靠白色把世界「照亮」

小世界與主世界同步調整：
- Tone mapping exposure 明顯降低。
- Bloom strength 降低、threshold 提高，只讓真正的魔法物件發微光。
- Bloom 與原畫面的混合比例大幅下降。
- 環境光 / 主光 / 補光全部降低。
- Toon gradient 最亮階不再是純白。
- 水面從亮青色改成更深、更沉穩的山水藍綠。
- 雲層改成帶主題色的雲，不再大量使用接近純白的材質。
- GLB 小木屋、亭子、長椅、鳥居等會重新套用該組世界的實際色彩，不再被強光洗成白色。
