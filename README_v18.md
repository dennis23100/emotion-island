# 情緒不孤島 v1.8 — Bug Fix + Eight Real Biomes

## 這次最重要的修正

### 1. 修正送分 / 切組時 `renderCurrent is not defined`
- 新增正式 `renderCurrent()`。
- 它會統一處理：世界階段、手動佈置、小精靈、控制面板、訪客面板。
- `buildWorld()` 在 group 資料尚未載入時不再因 render 函式不存在而中斷。
- 送分按鈕加入 try/catch/finally，不會卡在 disabled。
