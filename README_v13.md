# 情緒不孤島 v1.3 — Cinematic Art Pass II

這一版不是增加更多管理功能，而是把 v1.2 的遊戲美術架構再往「正式遊戲場景」推進。

## v1.3 主要升級

### 1. Selective Bloom / 電影光效
- 主世界與小世界都加入可選擇的 UnrealBloomPass。
- Bloom 只給指定的發光物件層：世界核心、星環、水晶、燈、篝火、瀑布、魔法粒子等。
- 一般草地、樹、房屋不會整片過曝。
- 右上新增「電影光效 / 流暢模式」切換。
- 如果 post-processing CDN 無法載入，會自動退回原本 WebGL renderer，不會讓整頁死亡。

### 2. 八組專屬環境 FX
- 星瀑島：星屑 + 流星
- 櫻光島：櫻色漂浮粒子
- 森語島：森林螢光粒子
- 晨曦島：暖金晨光粒子
- 月汐島：冷色月光星塵
- 花風島：粉紫花風粒子
- 晶語島：青色晶光粒子
- 希望島：極光簾 + 流星

### 3. NPC × 家具互動加深
小精靈現在除了散步與聊天，也會對家具出現不同反應：
- 長椅 / 野餐 / 涼亭：靠近後呈現坐下感
- 鞦韆：停留時上下擺動
- 觀星台：會抬頭觀星
- 篝火：聚集在較外圈並聊天
- 噴泉：會在周圍停留

### 4. 接觸陰影
手動擺放的家具下方加入輕量 contact/blob shadow，讓家具不再像貼在地面上。

### 5. 瀑布與魔法物件進入 Bloom Layer
瀑布、核心、發光環、水晶與魔法效果的光不再只是純白材質，而是能真正產生柔光外溢。

### 6. 效能保護
- 手機 Bloom 解析度與強度自動較低。
- 使用者可以手動切換成「流暢模式」。
- Post-processing 載入失敗時自動 fallback。

## 正式網址規則保持不變

主世界：

`emotion_island.html?room=0905`

各組：

- 第一組：`emotion_my_world.html?room=090501`
- 第二組：`emotion_my_world.html?room=090502`
- ...
- 第八組：`emotion_my_world.html?room=090508`

主辦方從大世界進第一組：

`emotion_my_world.html?room=090501&view=1&from=main`
