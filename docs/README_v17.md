# 情緒不孤島 v1.7 — World Polish / Score Flow Fix

這一版主要處理：小世界太暗、分數無法送出、第五組月亮異常、八組滿等展示不足，以及整體「像 Demo」的問題。

## 主要修改

### 1. 小世界重新平衡亮度
- 亮度調回 v1.5 與 v1.6 中間，不再整片暗掉，也不回到過曝白霧。
- 提高中間調與環境補光，保留清楚陰影。
- Bloom 降低強度、提高門檻，讓光效只當點綴。
- 八組 palette 全部重新拉到接近第八組的明度平衡，但保留各組顏色個性。

### 2. 第五組月汐島核心重做
- 移除原本容易看成斷裂／畸形的巨大月牙 Torus。
- 改成穩定的「潮汐月核」：藍灰月球、月面坑、雙層軌道與星辰。

### 3. 分數流程修正
- 移除 -50 / -100 等扣分按鈕。
- 不允許分數降低；要歸零請用主辦方重置。
- 「設定」改成「送出」。
- Enter 也可以送出。
- 修正 `toast is not a function`：現在有正式的本地 toast function，不再被 DOM id 全域變數覆蓋。
- 小世界與快速填分備用頁都同步更新。

### 4. 八組全滿等展示
本機／ChatGPT Demo（不帶 room）會使用新的 v1.7 localStorage key，因此重新建立展示資料：
- 8 組全部 1600 分
- 8 組全部 Lv.16
- 每組 16 隻小精靈
- 每組 16 件主題家具
- 每組都有不同世界名稱與 final layout

而且 v1.7 的示範家具位置是依照島上固定景物與家具 footprint 做過離線排版檢查，避免展示版家具互相穿模。

### 5. 世界美術再升一層
- 八組 palette 重新平衡。
- 新增地表微細節：草叢、石粒、花點，減少大片空草地。
- 每組島邊增加一圈主題式景物，強化 silhouette 與世界個性。
- 天體依主題區分：星球／晨日／月球／晶體感，不再每組都是同一顆背景球。
- 白色漂浮光球減少、縮小並改成主題色，避免再把畫面洗白。

## 展示模式
直接開：
- `emotion_my_world.html`

- 第八組：`emotion_my_world.html?room=090508`
