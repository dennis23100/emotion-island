# 情緒不孤島 v2.6 BIOME REBALANCE

這版不是再堆更多東西，而是把「空間、主題辨識度、可佈置性、觀看舒適度」重新平衡。
第八組的構圖與氛圍保留不動，作為這一輪的視覺基準。

## 第三組：森語秘境

問題：畫面漂亮，但樹木從中心一路塞到外圈，視覺上像一整片樹牆，也把玩家真正能佈置的空間吃掉。

修改：
- 拿掉原本環狀密集的 18 棵大樹生成方式，改成後方／外圍的疏林。
- 另外削減數個重複樹圈與內圈灌木群。
- 中央、前景、左右各留出清楚草坪，可實際拿來擺家具／遊樂設施。
- 新增林間溪流、草坪色塊、低密度花帶，保留森林味道但不再「全畫面都是樹」。
- 雲層縮小並推遠，避免巨大白雲遮掉畫面。

## 第四組：晨曦山庭

問題：顏色很漂亮，但構圖太空、主題故事感不足。

修改：
- 新增「晨曦日輪廣場」作為中前景視覺焦點。
- 加入一條藍綠色山澗，打破整片黃綠色造成的單調。
- 新增金色梯田／花田帶，形成明確的前景層次。
- 加入遠方光拱與天空光帶，讓晨曦主題更完整。
- 雲層縮小並推遠，減少前景巨大白色物件。

## 第六組：花風原野

問題：花田有顏色，但缺乏「一眼就記得住」的場景結構。

修改：
- 新增蜿蜒水道，讓島不再只是一大塊平坦花田。
- 改成兩塊有設計感的主花園，而不是平均撒滿小花。
- 左右加入花風拱門，建立入口／出口感。
- 增加兩條高空柔光花帶，讓遠景有層次而不是空白天空。
- 雲層縮小並推遠，畫面更乾淨。

## 第七組：晶湖聖域

問題：中央黑色區域持續跳動／閃爍，長時間觀看不舒服。

原因：舊版中央同時疊了多層透明水面、池面、底盤，深度太接近時會出現 WebGL z-fighting / transparent depth sorting 視覺抖動。

修改：
- 移除舊的大型重疊透明池面。
- 移除舊透明 `v24LakeRing`。
- 改成單一穩定、非透明、寫入 depth buffer 的晶湖水盆。
- 湖底、水面、內島、外環分開高度，避免共面競爭。
- 晶柱數量略降，讓中央湖更清楚、眼睛更舒服。
- 最佳視角降低俯視角度，不再一直盯著湖面幾何重疊區。

## 其他島

- 第一、二、五組不做大改，避免把已經穩定的畫面改壞。
- 第八組完全保留，因為它目前是八組中構圖／色彩／氛圍最接近目標的一組。
