# 情緒不孤島 v1.5 — 共感桃源 / Projection World Pass

v1.5 這一版主要做兩件事：

1. 把「主畫面」從八個小島＋中央山的展示頁，往真正的 **大世界／世外桃源投影畫面** 推。
2. 暫時重新開放「小世界切換組別」，讓開發測試時可以快速比較八組完整世界。

## 主畫面升級

### 共感聖山變成真正的主心骨
- 中央主島尺寸、厚度、地形層級全面增加。
- 新增三層聖山平台。
- 新增巨型「共感神木」作為大世界的中心視覺。
- 新增八個朝向各組的巨大地根／石脊，象徵中央世界承接八組。
- 新增 8 道瀑布、雙層光環、懸浮星燈、守護山峰。
- 若 GLB 資產正常載入，中央聖山會額外加入亭子、燈與鳥居／入口資產。

### 海與天空重新做
- 主海面換成動態 Shader：深藍、青藍、流光、細微亮點，不再是單色青色平面。
- 加入水下光帶與更低飽和的深水區。
- 天空改成深藍 → 靛藍 → 紫霞 → 暖色地平線的多層漸層。
- 加入柔和月體、月環、晚霞光源與漂浮光粒。
- 降低霧的密度，保留遠近景深但避免整個世界被洗白。

### 八島不再像杯子蛋糕
- 每座組別島從單純圓柱改成不規則、下方收束的浮島輪廓。
- 加入岩層肩部、草地唇緣、外圍岩塊與不規則地表。
- 八島視覺上更像自然浮島，不再像直立杯子／蛋糕底座。

### 「大家原來一直相連」正式做進世界
- 島 → 共感聖山：8 條能量連結。
- 島 ↔ 島：完整環狀連結。
- 連結不是 1600 分才突然出現，而是依每組進度逐步增加亮度與存在感。
- 進度越接近 1600，路徑越完整、光越強、流動粒子越明顯。

### 投影巡航
- 主畫面右上新增「自動巡航」。
- 開啟後鏡頭會非常慢地繞行大世界，適合投影長時間展示。
- 只要手動拖曳畫面，巡航會自動停止，立即交還控制權。

## 小世界開發／展示模式

### 「切換組別」重新開放
右上角新增：

`切換組別`

會打開八組選擇面板，可快速查看：
- 第一組：星辰山水
- 第二組：櫻霞庭園
- 第三組：翡翠森境
- 第四組：晨曦山谷
- 第五組：月汐夜海
- 第六組：花風原野
- 第七組：晶湖秘境
- 第八組：希望極光

若目前有未儲存佈置，切換前會先警告。

### 八組現在都有展示佈置
舊版雖然八組都有不同的自動 Biome 與主題景物，但「第一組」的手動展示佈置最完整。

v1.5 的本機 Demo 已改成：
- 八組全部 1600 分
- 八組全部 16 位小精靈
- 八組都有各自不同的一批示範家具／佈置
- 八組有不同世界名稱

所以現在切組就可以直接比較完整效果。

## 房間網址仍然相容

主畫面：
`emotion_island.html?room=0905`

第一組：
`emotion_my_world.html?room=090501`

第八組：
`emotion_my_world.html?room=090508`

測試時即使從 `090501` 切換到第二組，網址也會同步變成 `090502`，重新整理後仍會回到正確組別。

正式活動時，只要把「切換組別」按鈕再次鎖掉即可，底層的 090501～090508 架構不用重做。
