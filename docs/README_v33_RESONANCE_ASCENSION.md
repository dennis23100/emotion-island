# 情緒不孤島 v3.3 — RESONANCE ASCENSION

本版只升級大世界 `emotion_island.html`，小世界與分數頁完全凍結。

## 核心修正

- 0 分：島嶼頂端貼近海面，主要岩體仍在水下。
- 1600 分：整座外島岩體真正離開海面，不再出現「滿分島還坐在海上」的矛盾。
- 共感地脈不再永遠貼著海面。分數提高後，地脈從兩端出水，最後形成由高島向中央聖山下降的立體地形連結。
- 發光連線改為動態 3D 曲線，外島升高時端點會跟著升高；分數越高越亮、越粗，避免「島越高線反而消失」。
- 高成長島新增海面陰影與懸空瀑布，讓「這座島正在浮在空中」一眼可辨。
- 海浪紋降低交叉網格感，保留可辨識、較自然的流動波峰。
