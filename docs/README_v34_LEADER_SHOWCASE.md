# v3.4 LEADER SHOWCASE

這版只處理「大世界導覽」與新增一座獨立的主領班示範世界；凍結的小世界與分數頁沒有修改。

## 1. 世界導覽改成新分頁

- 第一組～第八組的「前往」全部使用新分頁。
- 主畫面會留在原本分頁，不需要再從小世界按返回才能找回主畫面。
- 仍保留原本 `room=202601 ... 202608` 的房號規則。

## 2. 新增「主領班 · 共感典範島」

世界導覽第一列新增：

- 主領班 · 共感典範島
- 官方示範世界 · 固定展示 · 不列入排行
- 連到 `emotion_leader_world.html`

這不是第九組：

- 不加入排行榜。
- 不建立第九個 score-driven island。
- 不讀取 Firebase 分數。
- 不會被「重置分數」或「重製八組小世界」清除。
- 不提供商店、佈置或編輯功能。

## 3. 主領班示範島內容

獨立 3D 世界預先完成：

- 巨型星願神木與發光願望吊飾
- 高低地形與三道瀑布
- 星圖廣場與噴泉
- 櫻花茶庭、池塘與木橋
- 晶石觀測區與望遠鏡
- 摩天輪
- 旋轉木馬
- 環島迷你列車
- 音樂舞台
- 篝火休憩區
- 花圃、長椅、燈路
- 16 位會活動的小精靈
- 動態螢火光點、星河光帶、海浪與電影巡航

目的不是提供第九組遊戲，而是讓參加者一進去就看到「自己的島最後可以有多豐富」。

## 4. 部署

至少把以下兩個檔案放在同一個網站目錄：

1. `emotion_island.html`（新版主畫面）
2. `emotion_leader_world.html`（新增的主領班示範島）

原本的 `emotion_my_world.html`、`emotion_score.html` 直接保留即可，本版沒有修改。
