# v3.5.0 Release Candidate

正式發布前整合版。

## 本版變更

- 主領班觀光列車改成每節車廂各自沿圓形軌道前進，不再整串車身切出軌道。
- 主領班摩天輪改成「固定支架 + 旋轉輪體 + 保持直立車廂」。
- 主畫面世界導覽改為同分頁進入小世界；小世界左上角提供返回大世界箭頭。
- 新增唯讀群島參觀模式：`emotion_gallery.html?room=2026`。八組可在同一頁上方切換，不顯示任何分數或排名，也不能編輯。
- 各組自己的小世界新增「參觀群島」按鈕。
- 清除正式版不需要的版本號、操作教學、長篇說明、角落註記等視覺雜訊。必要的佈置狀態提示與管理二次確認仍保留。

## 網址範例

- 大世界：`emotion_island.html?room=2026`
- 第一組：`emotion_my_world.html?room=202601`
- 唯讀群島：`emotion_gallery.html?room=2026`
- 主領班：`emotion_leader_world.html?room=2026`

## 導覽權限

- 大世界 -> 各組：同分頁、唯讀、左上返回箭頭。
- 各組自己的小世界：可填分、改名、小精靈、購買與佈置。
- 群島參觀：八組唯讀切換，不顯示分數。
