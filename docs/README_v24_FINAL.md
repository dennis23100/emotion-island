# 情緒不孤島 v2.4 FINAL SHOWCASE

這是「小世界」最後一次大型更新版。方向不是再增加功能，而是：

1. **先把佈置保存與底部操作列修到可靠**。
2. **把八組做成八個真正不同的世界構圖**，不是只換顏色。
3. **凍結已成熟的核心資料功能**，避免最後一次美術改版把分數 / 商店 / 房間 / NPC 改壞。

## 這次修掉的重大問題

### 儲存失敗
目前小世界實際有 118 個佈置格位（index 0～117），但舊資料層仍只接受 0～95。
因此外圈物件在保存時可能被丟掉，甚至造成草稿與已擁有物件數量不同步。

v2.4 改為：
- 佈置 API 支援 0～127，保留擴充空間。
- 真正保存目前 118 個格位。
- 可保存座標半徑同步放寬到新版大島範圍。
- 本機展示模式直接保存草稿，不再誤用多人同步的物品數量衝突檢查。
- Firebase 正式房間仍保留物品所有權檢查，防止多裝置複製家具。

### 底部四個按鈕「像沒反應」
- 旋轉：一定會出現「已旋轉 45°」回饋。
- 停止拿取：停止 ghost preview，但保留已暫放草稿，並明確提示。
- 取消未儲存：改成「兩次點擊確認」，不依賴嵌入式預覽可能攔截的 `confirm()`。
- 儲存：加入「儲存中… / 成功 / 失敗原因」和 try/catch，失敗不會吞掉草稿。

## 最終八世界視覺方向

1. **星瀑島 / 星辰天文境**：深色天文平台、星圖、觀測山脊、星座路線。
2. **櫻光島 / 櫻霞庭園**：斜向溪流、茶庭步道、大面積櫻花花園。
3. **森語島 / 翡翠森境**：森林盆地、環形林帶、世界樹聚落。
4. **晨曦島 / 晨曦山谷**：斜向高山稜線、金色步道、風之高地。
5. **月汐島 / 月汐夜海**：巨大潮汐水環、月燈海岸、觀星棧道。
6. **花風島 / 花風原野**：雙花野、嘉年華步道、花田構圖。
7. **晶語島 / 晶湖大峽谷**：中央晶湖水環、內島、左右高密度晶柱峽谷。
8. **希望島 / 希望極光**：對稱極光聖域、星圖祭壇、願望燈路。

第一組與第七組特別採用完全相反的構圖：
- 第一組：視線向「天空 / 高山 / 天文台」上升。
- 第七組：視線向「中央湖 / 左右晶谷」下沉與展開。
