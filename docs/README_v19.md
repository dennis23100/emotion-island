# 情緒不孤島 v1.9 — Wonderland Expansion

這一版主攻兩件事：
1. 分數改成「本次加分」而不是重新輸入總分。
2. 把小世界擴成更像可長期經營的遊戲島，新增大型遊樂設施與更大的佈置空間。

## 分數改動
- 小世界「分數」頁現在輸入的是本次增加的分數。
- 例：目前 1600，輸入 100 → 送出後變成 1700。
- +50 / +100 / +200 / +500 是快捷填入，仍要按送出，避免誤觸。
- 備用快速填分頁也同步改成累積加分。
- 世界成長仍以 1600 / Lv.16 為完整狀態；超過 1600 的分數會繼續累積並增加可用分數，可用來買更多設施。

## 小世界擴張
- 主島直徑由約 25.6 世界單位擴到約 32 世界單位。
- 浮島厚度、底部與外圈同步放大。
- 水域與鏡頭範圍同步擴張。
- 新增第 6 圈佈置區，總佈置槽由約 90 增至 118。
- 小精靈活動範圍擴大，不會全部擠在中央。

## 新增「遊樂」商店分類（全部 100 pt）
- 星願摩天輪
- 夢境旋轉木馬
- 月光咖啡杯
- 小世界觀光列車
- 天空飛椅
- 彩虹溜滑梯
- 雲朵彈跳床
- 熱氣球驛站
- 星願拍照亭
- 雲端迷你軌道

其中摩天輪、旋轉木馬、咖啡杯、列車、天空飛椅、熱氣球、彈跳床、迷你軌道都有動畫。

## 八組滿等展示
本機展示模式使用新的 V19 localStorage key，所以會重新生成：
- 八組全部 1600 分
- 每組 16 隻小精靈
- 每組 20 件示範佈置
- 每組都包含不同的遊樂設施組合
