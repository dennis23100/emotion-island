# 情緒不孤島 v2.5 FINAL ASSET REMASTER

這一版只做最後一輪「可購買物件美術重製」，核心資料與互動系統凍結。

## 重製物件

1. 觀星台
   - 三腳架、可辨識望遠鏡鏡筒、金屬轉軸、前鏡片與調焦環、石質觀測底座。
2. 篝火晚會
   - 石圈、交錯木柴、三層火焰與低強度火星，不再是一根橘色錐體。
3. 小小音樂台
   - 舞台、階梯、頂棚、麥克風、雙喇叭、舞台燈。
4. 風景畫架
   - 真正的木製畫架；畫布上有實際山水／湖泊畫面，另有調色盤。
5. 夢境旋轉木馬
   - 完整底座、華蓋、中心柱、金色裝飾、五隻可辨識小馬；保留旋轉與 NPC 座位錨點。
6. 小世界觀光列車
   - 雙軌、枕木、蒸汽火車頭、煙囪、車輪、乘客車廂；保留原本旋轉路線與 NPC 搭乘錨點。
7. 彩虹溜滑梯
   - 梯子、扶手、平台與四色彩虹滑道，而不是一根斜板。
8. 雲端迷你軌道
   - 雙軌、支柱、枕木、雲朵裝飾、真正的小車；保留 NPC 搭乘錨點。
9. 光之拱門
   - 石質拱門本體 + 內側真正發光的能量弧 + 水晶 + 星光粒子。
10. 森之鳥居
    - 獨立鳥居模型：雙柱、雙橫樑、翹角、注連繩、紙垂與匾額；不再和光之拱門共用模型。
11. 願望樹
    - 更大的樹幹、枝幹、層次樹冠、掛籤、彩色願望卡、星形徽記與微光吊飾。

## UI 小修
- 寬螢幕上的商店分類改為自動換行，避免醜的橫向捲軸。
- 預覽窗背景與邊框做小幅 polish，但預覽／購買流程沒有改。
