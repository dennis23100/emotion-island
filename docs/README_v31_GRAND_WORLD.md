# 情緒不孤島 v3.1 — GRAND WORLD / 主世界震撼強化版

本版只大幅更新 `emotion_island.html`（大世界主畫面）。

`emotion_my_world.html` 與 `emotion_score.html` 均未修改；小世界正式版資料與功能保持凍結。

## 主世界視覺升級

- 中央共感聖山增加更強的「主心骨」：世界心核、雙層天體光環、上層天空橋。
- 增加三座大型遠景浮島：左右浮空山域＋高空神殿島，形成更完整的近／中／遠景。
- 遠景浮島自帶樹林、環形光帶與垂落瀑布，不再只有中央一座大島。
- 新增橫跨天空的星河光路與移動光點，天空不再只是單純漸層背景。
- 增加夕霞光柱、瀑布落水光池與中央世界心核呼吸光效。
- 水面 shader 加入更明顯的夕霞反射、藍色水紋與高光。
- 鏡頭預設改成更低、更接近電影海報式構圖，讓中央聖山比例更宏偉。
- 新增輕微暗角、地平線光暈與細微 grain，讓投影畫面更集中。
- 所有大場景新增動畫都只作用在主世界：浮島緩慢漂浮、星河脈衝、世界心核旋轉、瀑布光池呼吸。

## 世界導覽與排行榜正式分離

右上現在有兩個完全獨立入口：

- `世界導覽`：只顯示八組世界名稱與「前往」，不顯示分數／排名。
- `🏆 排行榜`：獨立抽屜，顯示即時排名與分數。

排行榜前 3 名使用 podium 視覺，其餘名次以列表呈現。

## 分數仍會影響世界

主畫面本身不在各島旁直接貼分數。

每組分數會繼續控制：

- 該組遠方世界節點浮起高度
- 通往中央聖山的情緒水脈亮度
- 八組平均成長程度會提高中央「世界心核」與天體光環的亮度

所以排行榜負責「數字」，世界本身負責「視覺成長」。
