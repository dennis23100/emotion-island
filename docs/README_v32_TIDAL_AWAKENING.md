# 情緒不孤島 v3.2 — TIDAL AWAKENING

這一版只修改大世界 `emotion_island.html`；正式小世界與分數頁保持凍結。

## 這次的核心改動

### 1. 海洋改成真正會讀得出「波紋」的 stylized water
- GPU vertex displacement：四組不同方向/頻率的波浪一起移動。
- fragment shader 加入細波紋、交叉水紋、放射 ripple、夕霞反光與高光閃爍。
- 中央聖山外圍與八座組別島嶼各有水面呼吸環，讓島嶼與海面有接觸感。
- 沒有使用 THREE.Water 的全場景即時反射，避免為了水面把場景再 render 一次造成不必要的效能負擔。

### 2. 「一開始不要連起來」正式落地
- 0 分時光路 opacity = 0。
- 埋在海底的連結地形也完全隱藏。
- 分數上升後，連結地形從「島嶼端」與「中央聖山端」兩邊逐段升出水面。
- 越接近 1600 分，中央缺口才越完整閉合。
- 發光水脈比地形更晚出現，避免一開始就像八條雷射線。

### 3. 島嶼升起更有戲劇性
- 0 分：島體主要沉在海中，只允許較高的 landmark / 樹梢有機會露出。
- 1600 分：整座島完全離開海面。
- 使用 smoothstep 類 easing，不是線性硬上升。

### 4. 圖二那個「C」重做
原本是第五組月汐島的水平月牙符號，所以俯視時很像一個 C。
現在改成「月潮神龕」：
- 月色水池
- 石製底座
- 直立發光月牙
- 月珠
- 四盞月色燈

### 5. 大世界再補一層生命感
- 三道中央瀑布新增 mist / spray 粒子。
- 水面與島嶼周圍的 ripple 會持續緩慢呼吸。
- 降低偏灰霧感，略微提高對比與飽和感。
