# 情緒不孤島 v3.0 — 共感大世界 / Paradise Main World

這一版只大幅重做 `emotion_island.html`（主畫面）。`emotion_my_world.html`、`emotion_score.html` 與資料層皆不變。

## 視覺重構
- 主畫面不再把八座島整齊陳列成排行榜；改成真正的幻想世界地圖。
- 中央改為宏偉「共感聖山」：多層山體、世界樹、三道瀑布、神殿、橋、湖泊與森林谷地。
- 八組小世界改成遠中景世界節點，藏在完整世界構圖裡，不顯示組名標籤與分數。
- 天空改成藍紫到暖霞的動漫式日暮漸層；加入遠山、雲海、月亮、星點、水面與前景框景。
- 分數只驅動「小世界升起與通往主山的光路清晰度」，主畫面不顯示任何分數。

## 世界導覽
右上「世界導覽」才會展開 8 組入口，僅顯示組別 / 世界名稱與「前往」，不顯示即時分數與名次。

## 投影模式
- `電影巡航`：自動緩慢巡視完整世界。
- 拖曳、滾輪、右鍵平移都會立即停止巡航並交還手動控制。
- `光影` 可切換電影 Bloom / 流暢模式。

## Core Freeze
主世界仍沿用既有 EmotionData / Firebase / room 解析。
- `?room=2026` 主頁仍讀取 `rooms/2026/emotionV3/groups`。
- 第一組導向 `emotion_my_world.html?room=202601`，依此類推到第八組 `202608`。
- 小世界檔案未修改。
