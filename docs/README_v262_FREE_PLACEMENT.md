# v2.6.2 FREE PLACEMENT — 自由佈置修正版

這一版不是再放寬固定格位，而是把手動佈置真正改成「自由座標」。

## 為什麼 v2.6.1 還是不行
v2.6.1 仍然沿用 118 個固定 slot，只是把 slot 分成標準／彈性／保底三種。
所以大物件可能只剩 0～1 個合法點，而且 renderPlaced 仍會把家具吸回 slot 座標。
這和「想放哪就放哪」不是同一件事。

## v2.6.2 的新操作
1. 從庫存按「拿起來佈置」。
2. 場景內既有家具、NPC 與自動裝飾會變成半透明，方便看地面。
3. 物件跟著游標預覽，腳下顯示藍色方格；碰撞時方格變紅。
4. 拿著物件時，滑鼠／手指拖曳仍然可以旋轉視角；右鍵仍可平移，滾輪／雙指仍可縮放。
5. 單擊／單點地面只是「選擇位置」，不會立刻放下。
6. 按「✓ 確認放下」才把物件加入目前的佈置草稿。
7. 最後再按「儲存小世界」才同步到 localStorage / Firebase。

## 自由座標與相容性
- placement key 仍使用原本 0..127 的 ID，所以 Firebase / inventory / saveLayout 結構沒有改掉。
- 真正的位置改存 `x/z`；舊資料沒有 x/z 時，仍會以舊 slot 位置顯示，因此向後相容。
- 只保留島邊界、主要硬地形與其他已擺家具的碰撞；不再被大量景觀樹木／花草硬鎖在少數 slot。
- 「移動」舊家具時會帶著原本角度與大致位置進入自由佈置模式。
