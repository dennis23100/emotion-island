# v3.4.2 主領班・星願神境（MYTHIC SHOWCASE）

這版只重做 `emotion_leader_world.html`，不修改八組小世界、大世界主畫面、分數頁、Firebase/room 資料或排行榜。

## 這次不是「多擺幾個家具」

v3.4.1 的問題是：平坦島面、中央巨樹、摩天輪/列車/望遠鏡等一般商品平均散在島上，雖然東西很多，但仍像「展示架」。v3.4.2 改成真正的神話級示範樂園，新增大量主領班限定、商店買不到的地標：

1. **共感星宮**：八座小塔、中央穹頂、金色核心，與神木整合成主視覺。
2. **星環神木**：三層巨型天體光環＋環繞願望星光，不再只有一棵大樹。
3. **星河瀑布＋月鏡湖**：三道大型瀑布落入中央湖，建立真正的地形高低差。
4. **雲端觀星殿＋纜車**：高地觀測區、雙望遠鏡、晶石庭園、三台纜車持續運行。
5. **天空鯨**：大型低多邊形天空鯨會環繞世界巡遊，屬於完全不可購買的展示級地標。
6. **櫻月茶庭**：獨立櫻花高地、六角亭、暖粉燈路。
7. **神話遊樂區**：升級摩天輪、旋轉木馬、環島列車、光之入口、光之噴泉。
8. **夜祭舞台／篝火區**：以完整區域構圖呈現，不再像家具散落。

## 美術修正

- 主島改成更大的不規則浮島與多層地形，而不是平坦圓盤。
- 色彩改為森林綠、深藍岩壁、湖水青、櫻花粉、暖金，降低白色與過曝。
- ACES exposure 由 0.88 降為 0.82。
- Bloom threshold 提高到 0.96，只讓真正需要發光的物件亮。
- 標題面板預設收合，讓島本身成為第一視覺主角。
- 最佳視角與電影巡航重新拉遠，能一次看到完整神境與天空鯨。
