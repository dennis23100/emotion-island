# v3.4.1 主領班 Showcase Remaster

這版只重做 `emotion_leader_world.html`。主世界、八組小世界、分數頁與 Firebase/排名資料皆不修改。

## 為什麼重做
v3.4 主領班使用巨大淺色圓柱底座、整體曝光偏白、物件比例小且像散落展示品，視覺上反而低於已完成的小世界。

## v3.4.1 的構圖原則
- 不再用巨大白色圓柱：改成不規則、多層岩壁的浮島輪廓。
- 不把家具平均散開：把內容整理成完整區域。
- 白色只留作少量高光；主要色彩是森林綠、櫻花粉、湖水青、暖金、深藍岩層。
- Bloom 強度壓低、threshold 拉高，避免整座島泛白。

## 六個主要區域
1. 中央星願神木高地：彩色樹冠、願望籤、暖色心光。
2. 左側櫻花茶庭：櫻樹、六角亭、茶桌、鳥居。
3. 右後觀星高台：雙望遠鏡、晶石花園、獨立高地。
4. 右前遊樂園：摩天輪、旋轉木馬。
5. 前庭生活區：音樂舞台、篝火、畫架、長椅、花圃。
6. 溪谷水景：山坡溪流、池塘、雙瀑布與木橋。

另外保留環島觀光列車、16 位小精靈與大量環境粒子，讓 Showcase 在投影時也持續有生命感。

## 部署
主世界已經連到 `emotion_leader_world.html`，所以部署時只需用此版本覆蓋同名檔案即可。其餘正式檔案不必更換。
