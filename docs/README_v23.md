# 情緒不孤島 v2.3 — BIOME IDENTITY PASS

這一版的單一目標：**讓八個小世界第一次真的像八張不同的遊戲地圖，而不是同一座島換顏色。**

## 這一版沒有重寫的核心

以下核心函式與 v2.2.2 穩定母版做函式級比對，保持不變：

- addScore
- buyItem
- saveLayout
- placeItem
- setWorldName
- saveMember
- selectGroup
- renderPlaced
- renderPeople

也就是說，這一版主要改 Render / Biome / Lighting / Camera Preset，不改分數、商店、佈置資料格式、房間、切組等核心資料流程。

## 每組 Lighting 也不再共用一套

v2.3 新增 `BIOME_LIGHT_V23`：
- 每組有不同主光方向
- 不同 Fill Light 強度
- 不同 Hemisphere Light
- 不同 Exposure

因此世界差異不只來自 palette，而是構圖和明暗方向也不同。
