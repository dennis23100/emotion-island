# 情緒不孤島

Three.js 打造的即時互動加分系統。八個小組各自擁有一座島，累積分數換取商店道具並佈置自己的世界，資料即時同步到 Firebase Realtime Database。

正式版 **v3.5.0**，小世界為 **v3.5.1**（手機渲染修正）。

## 頁面

| 檔案 | 說明 |
| --- | --- |
| `emotion_links.html` | **連結產生器** — 輸入房號，一次產生所有連結 |
| `emotion_island.html` | 共感大世界 — 投影用主畫面，幻想世界地圖、世界導覽、獨立排行榜 |
| `emotion_my_world.html` | 我的小世界 — 單組自由佈置、商店、預覽、購買、加分 |
| `emotion_gallery.html` | 群島參觀 — 唯讀瀏覽八組，可直接切換，不顯示分數 |
| `emotion_leader_world.html` | 主領班 · 星願神境 — 官方示範世界，固定展示 |
| `emotion_score.html` | 快速填分 |

主領班示範島**不是第九組**：不讀 Firebase 分數、不列入排行、不提供商店與佈置，也不會被「重置分數」清除。它的用途是讓參加者一進去就看到自己的島最後能有多豐富。

## 權限

| 入口 | 權限 |
| --- | --- |
| 各組自己的連結 `?room=202601` | **可編輯** — 填分、改名、小精靈、購買、佈置 |
| 大世界的「前往」 | 唯讀（自動帶 `view=1`），同分頁進入，左上返回箭頭 |
| 群島參觀 | 唯讀，八組可直接切換，不顯示分數 |
| 主領班示範島 | 唯讀，不連 Firebase |

## 網址參數

| 用途 | 網址 | 解析結果 |
| --- | --- | --- |
| 主畫面 | `emotion_island.html?room=2026` | 房間 2026 |
| 第一組 | `emotion_my_world.html?room=202601` | 房間 2026、第 1 組 |
| 第八組 | `emotion_my_world.html?room=202608` | 房間 2026、第 8 組 |
| 唯讀參觀 | 上述網址加 `&view=1` | 隱藏編輯面板 |

各組連結使用**組別房號**（4 碼房間 + 2 碼組別），組別包在房號裡，資料仍寫回同一個房間，所以九個連結完全連動。也可以改用明確參數 `?room=2026&group=1`，兩種寫法皆可。

直接開啟 `emotion_links.html` 就能產生全部連結，不需要手動組網址。

## 分數與小精靈

| 項目 | 規則 |
| --- | --- |
| 開場可用點數 | **500**（`START_POINTS`），僅供佈置，不計入分數 |
| 開場分數 | 0 |
| 加分 | 分數與可用點數**同時**增加相同數值 |
| 小精靈解鎖 | 每 **100 分**一位，不花點數 |
| 小精靈上限 | 各組在「小精靈」欄自訂，1～30，預設 10 |

例：開場為 `500 點 / 0 分 / 0 精靈`；加 100 分後變成 `600 點 / 100 分 / 1 精靈`。

上限預設是 10，所以滿分 1600 也只會出現 10 位；**組員多於 10 人的組別要自己把上限調高**。

已存在於資料庫的組別不會被追加開場點數（避免覆蓋已花掉或賺到的點數）。活動開始前執行「重置分數」即可讓八組回到 `500 點 / 0 分`。

## 背景音樂

`music/` 放 `.mp3`，`assets/bgm.js` 隨機洗牌播放，各頁右下角有音符按鈕可開關（預設開啟，記憶於 localStorage）。換頁時以 sessionStorage 接續歌曲與秒數。

瀏覽器禁止使用者互動前自動播放，因此第一次進站會等到第一次點擊才出聲，按鈕會呈現待播的呼吸效果。

新增歌曲要同時把檔名加進 `assets/bgm.js` 的 `TRACKS`（靜態網站無法列出目錄內容）。

## 資料結構

- Firebase Realtime Database：`rooms/{room}/emotionV3/groups/{group}`
- 未帶 `room` 參數時為本機示範模式，資料存於 localStorage（前綴 `emotionIslandV24:`）

## 目錄

| 資料夾 | 內容 |
| --- | --- |
| `assets/` | `assetbank.js` 模型清單、`models/` 21 個 `.glb` 場景模型 |
| `docs/` | 各版說明、藝術方向研究、部署與升級筆記 |
| `verify/` | 各版驗證與靜態檢查報告 |
| `tools/` | 歷次版本的 patch / verify / regression 腳本 |
| `backups/` | v2.0、v2.2.2、v3.0、v3.1 主程式備份，與 v3.4 示範島備份 |

`tools/` 內的腳本使用產生當時環境的絕對路徑，保留作為改版紀錄，無法直接執行。

## 模型

`assets/models/` 收錄 21 個 `.glb`：樹木（橡木／松木／櫻花）、涼亭、燈籠、水晶、長椅、橋、營火、小屋、鳥居、望遠鏡、岩石群，以及 8 個 hero 建築（世界樹、水晶教堂、月神殿、觀星台、茶亭、風神殿、花亭、極光祭壇）。

這些模型由**小世界**使用。大世界自 v3.0 起改為程式生成場景，不再載入 `assets/` 或 GLTFLoader。

### v3.5.1 MOBILE RENDER HOTFIX（僅小世界）

只更新 `emotion_my_world.html`，修正手機端渲染：抑制陰影 acne、改用行動裝置安全的後製效果（手機上光影按鈕顯示為「穩定光影」，桌機仍為「電影光效」）、加入遠景剪影。

### 部署時的修正

原始檔的 `emotion_island.html` 把 `document.write` 的結束標籤寫成 `<\\/script>`（兩個反斜線），產生的字串是無效的 `<\/script>`，HTML 解析器因此無法關閉寫入的 script 元素，會吞掉第二個 firebase 腳本與整段 `EmotionData` 資料模組。症狀只在帶 `?room=` 時出現，純語法檢查偵測不到。本倉庫已改回 `<\/script>`，共 2 處。同一問題在 v3.3.1、v3.4.1、v3.5.0 各出現一次，皆已修正。

## 大世界 v3.3.1 說明

主畫面自 v3.0 起整個重做，從「八島排行榜」變成一張真正的幻想世界地圖。

- 中央為**共感聖山**：多層山體、世界樹、三道瀑布、神殿、橋、湖泊與森林谷地
- 八組小世界是遠中景的世界節點，島上不貼組名與分數
- 分數只驅動**視覺成長** —— 島嶼從海面升起的高度、通往聖山的地脈與光流亮度
- 右上分成兩個獨立入口：`世界導覽`（只有組別與「前往」）與 `🏆 排行榜`（名次與分數）
- `電影巡航` 自動巡視全景，任何拖曳／滾輪／右鍵會立刻交還手動控制

**v3.3.1 只修島嶼數量**：移除 v3.1／v3.3 加入的 3 座裝飾用浮島，因為它們看起來像第 9～11 組。現在固定為 8 座組別島 + 1 座中央共感主島，遠景深度改由雲、遠山、星河、光束與前景岩林負責。

## 部署

純靜態網站，three.js 由 CDN 載入，無建置流程。把根目錄指向任何靜態主機（Vercel／Netlify／GitHub Pages）即可。
